tinylsm

An embedded, persistent, write-optimized key-value store. This page runs the real C++20 engine compiled to WebAssembly on an in-memory filesystem: the append-only write-ahead log, the concurrent skip-list memtable, prefix-compressed SSTable blocks, Bloom filters, the LRU block cache, and leveled compaction are the same code paths the native build ships.

  • C++20 · zero external dependencies
  • CRC32-checksummed WAL
  • skip list p=0.25 · max height 16
  • Bloom filters · 10 bits per key
  • leveled compaction · 10x per level
  • MEMFS · no server
